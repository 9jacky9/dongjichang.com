在苹果 iOS 设备的代理软件生态中，**Shadowrocket**（因其带有火箭标志的图标，常被国内用户亲切地称为“小火箭”）绝对是稳坐头把交椅的王者。相比于 Surge 动辄大几十美元的昂贵售价，以及 Quantumult X 相对陡峭的学习曲线，Shadowrocket 以其 $2.99 的亲民价格、极低的内存占用、出色的省电优化，以及对市面上几乎所有主流代理协议（Shadowsocks、Vmess、Vless、Trojan、TUIC、Hysteria2 等）的完美支持，成为了几乎所有苹果用户的首选。

然而，由于苹果应用商店的区域政策，这款神器并未在中国大陆的 App Store 上架，导致很多新手在“如何获取”的第一步就被难住了。即使成功下载，面对眼花缭乱的路由规则、策略组、UDP 转发等专业词汇，很多用户也往往只停留在“能翻就行”的基础阶段，白白浪费了这款软件强大的进阶功能。

这篇硬核指南将带你从最基础的账号准备与下载，一路深入到策略组配置、按需连接（On-Demand）设定以及 UDP 游戏加速转发，真正发挥出这架“小火箭”的全部实力。

## 第一阶段：准备工作与软件下载

如前所述，如果你在国区 App Store 搜索 "Shadowrocket"，搜出来的全都是带有欺骗性质的伪装软件（甚至是借用同样图标的垃圾 VPN）。要下载真正的 Shadowrocket，你**必须**拥有一个**非中国大陆区（如美区、港区、日区）的 Apple ID**。

### 1. 获取非国区 Apple ID
这里有三种常见的途径：
- **自己动手注册**：去苹果官网（apple.com）注册一个全新的 Apple ID，地区选择美国。你可能需要准备一个没有注册过 Apple ID 的邮箱，以及一个美国地址生成器生成的信息。这是最安全、最推荐的方式，拥有一个独立的海外账号能为你后续下载 Netflix、TikTok 等海外 App 提供长久便利。
- **借助机场提供的公共账号**：许多服务优质的机场，为了方便新手，会在购买套餐后的后台面板里，免费提供公用的美区 Apple ID 供用户下载软件。
- **发卡平台购买独享账号**：如果你觉得注册太麻烦，可以通过正规的发卡网花十几块钱购买一个独享的美区账号。

### 2. 安全登录 App Store (⚠️ 致命警告)
如果你使用的是别人提供的公共账号，**绝对、绝对不要**在手机系统的“设置”最顶端登录！这会导致你的 iCloud 数据被同步到公共账号上，甚至恶意号主可以通过“查找我的 iPhone”功能直接远程锁定你的手机，敲诈勒索！

**正确的登录操作路径**：
1. 打开手机主屏幕上蓝色的 **App Store** 图标。
2. 点击右上角的个人头像，划到页面最底部，点击“退出登录”。
3. 划回到页面顶部，填入非国区 Apple ID 的账号和密码进行登录。如果提示需要升级双重认证，请选择“其他选项”并跳过。

### 3. 购买与下载
在美区 App Store 搜索框输入 `Shadowrocket`。请仔细核对以下信息：
- 开发者必须是 **Shadow Launch Technology Limited**。
- 图标是一个带有深蓝色背景的白色向上飞行的火箭。
- 软件是收费的，目前售价为 $2.99 美元。
- 如果你使用的是机场提供的公用已购账号，可以直接点击云朵图标免费下载。

> [!IMPORTANT]
> 下载完成后，请立刻回到 App Store 的头像处退出海外账号，并重新登录回你自己的国区 Apple ID。软件日常的使用和更新不需要一直挂着海外账号，请确保你的日常数据安全。

## 第二阶段：核心步骤——导入机场订阅

有了这架“火箭”，接下来我们需要为它注入“燃料”——也就是机场提供的节点服务器。

1. 登录你购买的机场后台（直接使用手机自带的 Safari 浏览器即可）。如果你还没有靠谱的机场，欢迎前往我们的 [评测榜单](/blog/best-airports-2026) 挑选一家适合你的品牌。
2. 在机场仪表盘找到类似 **“一键订阅”** 或 **“导入至 Shadowrocket”** 的按钮。点击后，手机通常会自动唤起小火箭，并弹出一个确认窗口。
3. **手动添加法**：如果你遇到了无法唤醒的情况，可以点击后台的 **“复制订阅链接”**。接着打开小火箭，点击首页右上角的 **加号 (+)**，第一行的“类型”选择 `Subscribe`，在第二行“URL”处长按粘贴刚才复制的链接，最后点击右上角的“保存”。
4. 回到小火箭首页，等待几秒钟，页面会自动刷新出你购买套餐中包含的所有国家和地区的节点列表。

## 第三阶段：全局路由与策略组的艺术

很多小白用户导入节点后，随便点了一个节点，打开总开关就去上网了。结果发现不仅看 YouTube 卡，甚至连国内的微信、淘宝、抖音都变得奇慢无比。这就是因为没有正确配置“全局路由”。

### 1. 认识全局路由 (Global Routing)
在小火箭的首页中间位置，你可以看到“全局路由”选项，点击进去有四个核心模式：
- **配置 (Config)**：**强烈推荐的默认模式**。这相当于电脑端常说的“规则模式”。小火箭会根据内置的规则列表进行智能分流——当你访问百度、淘宝等国内网站时，直接走你本地的网络（不耗费机场流量且速度快）；当你访问 Google、X(Twitter) 时，自动走代理节点。
- **代理 (Proxy)**：即“全局代理”。无论你访问什么网站，所有流量全部强行经过机场节点。通常只在“配置”模式下某些国外网站打不开时，作为临时排错手段使用。
- **直连 (Direct)**：等于关闭翻墙功能，所有流量不走代理。
- **场景 (Scene)**：根据你所处的不同网络环境（比如在公司 Wi-Fi 连某个节点，在家里连另一个节点）自动切换规则，属于进阶的高级玩法。

### 2. 深入理解策略组 (Policy Groups)
当你导入机场订阅时，大多数优秀的机场已经为你预设好了相关的“策略组”。但在日常使用中，如果你想拥有更极致的体验，需要理解这些策略组背后的逻辑。
小火箭支持多种策略组类型：
- **select (手动选择)**：将一批节点打包在一起，你需要手动点击选择使用哪一个节点。最常用于“节点选择”这一总控策略。
- **url-test (自动测速选择)**：小火箭会在后台定期对该组内的所有节点进行并发测速（通常是向指定的 URL 发送请求，比如 Google），并自动为你切换到当前延迟最低、速度最快的节点。这对于追求无缝体验、不想手动切节点的用户非常友好。
- **fallback (可用性回退)**：按顺序排列节点，平时一直使用第一个节点；当第一个节点故障无法连接时，自动切换到第二个节点。常用于关键任务的备用容灾。
- **load-balance (负载均衡)**：将流量分散到多个节点上，适合拥有多条低延迟专线的土豪机场，能显著提升大文件下载和多线程请求时的并发速度。

> [!TIP]
> **如何打造 Netflix 专属策略？**
> 你可以自己新建一个名为 `Netflix` 的策略组（类型选 select），然后把所有标有“流媒体解锁”或新加坡/台湾地区的节点放进去。接着去小火箭的“配置”里添加一条规则：遇到 `netflix.com` 相关的域名，统统走你刚才创建的 `Netflix` 策略组。这样你就可以在日常上网用香港节点的同时，看剧自动切到新加坡节点，互不干扰！

## 第四阶段：高阶玩家必备的隐藏技能

当你掌握了基础和路由之后，以下这些高级特性将极大提升你的网上冲浪体验，让你的小火箭不仅是翻墙工具，更是一个强大的网络管理中枢。

### 1. 开启 On-Demand（按需连接）：永不断线的秘密
很多用户抱怨：“为什么我每天早上起床，小火箭就断开了，还要重新打开软件点一次开关？”其实 iOS 系统内置了非常强大的 VPN 按需唤醒功能，小火箭完美支持了这一点。

**配置方法**：
1. 点击小火箭底部导航栏的 **“设置 (Settings)”**。
2. 找到 **“按需连接 (On Demand)”** 选项，将其开关打开。
3. 在下方可以配置详细的触发条件。比如：你可以设置当连接名为 `Company_WiFi` 时，自动**断开**小火箭（因为公司可能是内网环境）；当离开 Wi-Fi 切换到蜂窝移动网络 (Cellular) 时，自动**连接**小火箭。
4. **Action 机制**：将默认的“断开连接”调整为始终保持连接。

开启按需连接后，即使小火箭在后台被系统强杀清理掉内存，当你的手机有网络请求触发规则时，iOS 系统会在底层瞬间重新拉起 VPN 通道。这意味着你可以真正的“一次开启，永远忘记它的存在”，实现全天候的无缝翻墙，并且因为小火箭极佳的功耗控制，并不会给你的 iPhone 电池带来明显的负担。

### 2. 开启 UDP 转发：游戏玩家与语音通话的救星
你在玩诸如《绝地求生 (PUBG Mobile)》国际服、《Apex 英雄》等外服游戏时，或者使用 Discord、WhatsApp 拨打语音/视频电话时，经常会遇到延迟极高甚至根本连不上的情况，而看网页看视频却一切正常。
这是因为网页浏览主要依靠 TCP 协议，而实时对战游戏和语音通话为了追求极低延迟，大量使用 **UDP 协议**。默认情况下，部分代理环境对 UDP 的支持并不好。

**如何在小火箭中开启并优化 UDP**：
1. **确认机场支持**：首先，你要确保你购买的机场节点本身支持 UDP 转发（通常使用了 IPLC 专线或支持 FullCone NAT 的机场才会完美支持 UDP）。
2. **全局开启**：进入小火箭的 `设置 -> UDP`，确保 UDP 转发开关处于**开启**状态。
3. **节点独立配置**：如果你是手动添加的 Shadowsocks 或 Trojan 节点，点击节点右侧的 `i` 图标进入详情，确保其中的 `UDP 转发` 选项被勾选。
4. **NAT 类型优化**：在进行主机游戏（如搭配热点给 Switch 加速）时，如果你发现匹配困难，可以在 UDP 设置中将超时时间适当拉长（例如 60 秒），以更好地维持 NAT 穿透状态。

### 3. 模块 (Modules) 与复写 (Rewrite)
这是小火箭媲美 Surge 的高级特性。通过导入第三方大佬编写的模块脚本，小火箭能够在网络底层对数据包进行修改（也就是中间人攻击 MitM 技术的一种正向应用）。
- **去广告**：通过匹配规则，直接在网络层拦截各大视频 App 和网页的广告请求。
- **解锁 TikTok**：无需拔电话卡，通过复写规则修改 TikTok 发送给服务器的国家代码请求，轻松刷到美区、日区的短视频。
- **使用方法**：进入 `配置 -> 模块`，点击右上角加号，粘贴网络上开源的模块 URL 即可直接生效。注意，涉及 HTTPS 解密的模块通常需要你在 `设置 -> 证书` 中安装并信任小火箭的根证书。

## 第五阶段：日常维护与常见问题排查

为了让你的翻墙体验始终保持丝滑，建议花一分钟完成以下这两项基础的日常维护设置。

### 1. 自动更新订阅，告别节点失效
机场为了应对防火墙的封锁，会不定时地更换服务器 IP。如果你不更新订阅，你手里拿到的就是旧的、已经失效的节点信息。
**最佳实践**：进入小火箭 `设置 -> 订阅 (Subscribe)`，勾选 **“打开时更新 (Update on open)”**。并且开启下方的“后台自动更新”。这样小火箭会在你不经意间自动与机场服务器同步，你永远不用担心节点大面积超时失效。

### 2. 延迟测试的玄学：ICMP vs TCP
为什么小火箭里测速只有 50ms，但打开网页还是觉得卡？
因为默认的测速只是测试了你到机场入口服务器的延迟，并不是真正到达目标网站的延迟。
**优化方法**：
进入 `设置 -> 延迟测试 (Delay Test)`。
- **测试方法 (Method)**：建议将默认的 TCP 更改为 **ICMP**。这能更直观地反映节点服务器到底有没有“活”着，以及底层网络的真实连通性。
- **测试 URL**：如果你更在意真实的网页加载速度，可以将 URL 改为 `http://www.google.com/generate_204`。这种方式能真实反馈出该节点从请求到 Google 握手成功的完整耗时，测试出来的结果（比如 300ms）往往比虚假的 50ms 更有参考价值。

### 3. 解决 DNS 泄露与污染 (DNS 设置优化)
很多用户在访问某些特定网站时，明明开启了代理却依旧打不开，或者被重定向到了反诈页面。这很可能是因为你的 DNS 发生了泄露，或者依然在使用国内运营商被污染的 DNS 进行域名解析。
小火箭内置了强大的 DNS 解析模块。
**优化建议**：
1. 进入小火箭底部 `设置 -> DNS`。
2. 确保开启了 **“覆写系统 DNS”**。
3. 在本地 DNS 中，强烈推荐使用加密的 DNS 协议（如 DoH 或 DoT）。你可以删除默认的 `system`，添加例如 `https://dns.cloudflare.com/dns-query` (Cloudflare 1.1.1.1) 或者 `https://dns.google/dns-query` (Google 8.8.8.8)。
4. 这样一来，你的所有域名解析请求也会经过加密并由海外权威服务器处理，彻底杜绝了网络层面的 DNS 劫持，极大提升了访问部分敏感网站的安全性和成功率。

Shadowrocket 绝不仅仅是一个简单的开关。从基础的路由分流，到高阶的按需唤醒和 UDP 转发，它几乎把 iOS 系统的网络接管权限发挥到了极致。花半个小时配置好你的策略组和按需连接，在未来的无数个日夜里，你都将享受到无缝、自由且极速的国际互联网体验。
