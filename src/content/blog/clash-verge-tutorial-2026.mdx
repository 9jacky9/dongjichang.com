随着初代 Clash for Windows (CFW) 的停更，目前在 Windows 和 macOS 平台上，最好用的开源替代品非 **Clash Verge** 莫属（或是基于 Meta 内核的 Clash Verge Rev）。它不仅界面更现代，还内置了中文支持，配置起来比以前更加简单。

本教程将带你从零开始，在电脑上安装、配置并顺利使用这款最主流的代理软件。

## 第一步：下载与安装

### 1. 获取安装包
Clash Verge 是一款开源软件，推荐始终前往其官方 GitHub 的 Releases 页面下载最新版本：
- **Windows 用户**：下载以 `.exe` 结尾的安装程序（通常带有 `x64-setup` 字样）。
- **macOS 用户**：如果是 M1/M2/M3 等苹果芯片，请下载带有 `aarch64` 或 `arm64` 的 `.dmg` 文件；如果是老款 Intel 芯片，请下载带有 `x64` 的 `.dmg` 文件。

### 2. 执行安装
- 下载完成后，双击运行安装包。
- Windows 用户如果遇到系统弹窗提示“Windows 已保护你的电脑”，点击“更多信息” -> “仍要运行”即可。
- 安装过程一路点击“下一步”，直至完成。

## 第二步：设置界面汉化（如需）

最新版的 Clash Verge Rev 通常会在首次启动时自动跟随系统语言显示为中文。如果你的界面仍然是英文，请按照以下步骤操作：

1. 在软件左侧边栏找到并点击 **Settings（设置）**。
2. 往下滚动找到 **Language（语言）** 选项。
3. 将其从 `English` 切换为 `简体中文`。
4. 此时界面应该会自动刷新为中文。

## 第三步：导入机场订阅链接

有了软件，我们还需要“节点”才能上网。这需要用到你购买的机场提供的“订阅链接”。

1. 登录你购买的机场后台（如果你还没有机场，可以参考我们的 [机场推荐榜单](/blog/best-airports-2026)）。
2. 在后台仪表盘找到 **“一键订阅”** 或 **“复制 Clash 订阅链接”** 按钮，点击复制。
3. 打开 Clash Verge，点击左侧边栏的 **订阅（Profiles / Subscriptions）**。
4. 在页面顶部的输入框中，粘贴你刚刚复制的订阅链接，然后点击旁边的 **导入（Import）** 按钮。
5. 稍等片刻，软件会自动从机场服务器下载节点配置。你会看到列表中多出了一个配置项，**点击选中它**（确保它前面有一个被勾选的状态）。

## 第四步：选择代理模式与节点

配置导入成功后，我们还需要告诉软件如何处理你的网络流量。

1. 点击左侧边栏的 **代理（Proxies）**。
2. 在页面顶部，你会看到三个模式选项，这是最重要的一步：
   - **规则模式（Rule）**：最推荐的日常模式。国内网站直连（不费机场流量），国外被墙网站自动走代理。
   - **全局模式（Global）**：所有流量（包括国内网站）全部强制走代理。一般只在特定需求下使用，日常极度不推荐，不仅浪费流量还会导致微信/淘宝卡顿。
   - **直连模式（Direct）**：关闭代理，所有流量直连。
   👉 **请确保你选择了“规则模式（Rule）”。**
3. 往下看，你会看到一个名为 `PROXIES` 或者 `节点选择` 的策略组。展开它，你可以手动点击选择一个你喜欢的地区节点（比如 `香港 01`）。
   - 有些机场会提供类似 `UrlTest` 或 `自动选择` 的选项，它会自动帮你挑延迟最低的节点，新手可以直接选这个。

## 第五步：开启系统代理

节点选好了，最后一步就是让软件接管你电脑的网络。

1. 回到左侧边栏的 **设置（Settings）**。
2. 找到 **系统代理（System Proxy）** 选项，将其右侧的开关打开（变成亮色）。
3. （可选）如果你希望每次开机自动运行，可以顺手把 **开机自启（Start at login）** 的开关也打开。

至此，所有的配置都已经完成！你可以尝试在浏览器中打开 Google 或 YouTube，享受畅快的网络世界了。

## 常见问题排查

**Q: 开了系统代理还是无法访问外网？**
- 检查你的电脑系统时间是否准确，相差超过一分钟可能导致连接失败。
- 检查机场套餐是否已经过期或者流量用尽。
- 尝试在“代理”页面更换一个节点。
- 关闭电脑上的其他安全软件（如 360）或浏览器代理插件（如 SwitchyOmega），防止冲突。

**Q: 为什么 Telegram (电报) 还是连不上？**
- 某些版本的 Telegram 需要手动在软件内部设置代理。你可以在 TG 的设置中，开启使用系统代理（Use System Proxy），或者手动配置 HTTP 代理，地址通常为 `127.0.0.1`，端口为 `7890`（具体端口可在 Clash Verge 设置页面查看）。
