随着初代 Clash for Windows (CFW) 的停更，目前在 Windows 和 macOS 平台上，最好用的开源替代品非 **Clash Verge** 莫属（目前社区主推的是基于 Meta / Mihomo 内核的 **Clash Verge Rev** 版本）。它不仅界面更现代（基于 Tauri 框架构建，占用极低），默认内置了对各种新协议（如 VLESS、Reality、Hysteria 2）的支持，而且内置了中文支持，配置起来比以前更加直观和强大。

本教程将带你从零开始，在电脑上安装、配置并顺利使用这款目前最主流、功能最强大的桌面端代理软件。涵盖从基础的系统代理设置，到进阶的 TUN（虚拟网卡）模式开启、分流规则自定义等高阶玩法。

## 第一步：下载与安装

### 1. 获取正确的安装包
Clash Verge Rev 是一款开源软件，推荐始终前往其官方 GitHub 的 Releases 页面下载最新版本。由于不同电脑的架构不同，请务必下载对应的版本：

- **Windows 用户**：
  - 如果你是常规的 Intel 或 AMD 处理器，请下载带有 `x64-setup.exe` 字样的安装包。
  - 也有 `x64-portable.zip`（便携版），解压即用，适合放在 U 盘里或不想写入注册表的用户，但便携版在配置 TUN 模式时可能需要手动提权。
  - 如果你是高通骁龙处理器的 Windows 电脑（如 ARM 架构的新款 Surface），请下载 `arm64-setup.exe`。
- **macOS 用户**：
  - M1/M2/M3 等苹果自研芯片机型，请下载带有 `aarch64` 或 `arm64` 字样的 `.dmg` 文件。
  - 老款 Intel 芯片的 Mac，请下载带有 `x64` 的 `.dmg` 文件。

### 2. 执行安装与系统权限
- 下载完成后，双击运行安装包。
- **Windows 注意事项**：如果你遇到系统弹窗提示“Windows 已保护你的电脑（SmartScreen 筛选器）”，这仅仅是因为开源软件没有花钱购买昂贵的企业代码签名证书。点击弹窗上的“更多信息”，然后点击右下角的“仍要运行”即可。
- **macOS 注意事项**：首次打开可能会提示“软件损坏”或“无法验证开发者”，需要前往「系统设置」->「隐私与安全性」，往下拉找到并允许 Clash Verge 运行。

## 第二步：基础设置与界面汉化

最新版的 Clash Verge Rev 通常会在首次启动时检测你的操作系统语言，并自动显示为中文。如果你的界面仍然是英文，请按照以下步骤手动调整：

1. 在软件左侧边栏找到并点击 **Settings（设置）**。
2. 往下滚动找到 **Verge Setting（Verge 设置）** 区域，找到 **Language（语言）** 选项。
3. 将其从 `English` 切换为 `简体中文`。
4. 此时界面会瞬间刷新为中文。为了更好的护眼体验，你也可以在旁边的 **Theme（主题）** 里切换为深色模式（Dark）。

## 第三步：导入机场订阅链接

有了软件，我们还需要“节点”才能连接国际互联网。这需要用到你购买的机场提供的“订阅链接”（Subscription URL）。

1. 登录你购买的机场后台（如果你还没有满意的机场，可以参考我们的 [2026 高性价比机场推荐榜单](/blog/best-airports-2026)）。
2. 在机场后台仪表盘找到 **“一键订阅”** 或 **“复制 Clash 订阅链接”** 按钮，点击复制。如果机场有细分选项，请优先复制“Clash Meta 订阅”。
3. 打开 Clash Verge，点击左侧边栏的 **订阅（Profiles / 配置文件）**。
4. 在页面顶部的输入框中，粘贴你刚刚复制的订阅链接，然后点击旁边的 **导入（Import）** 按钮。
5. 稍等几秒钟，软件会自动从机场服务器下载节点配置文件。列表中会多出一个带有你机场名字的配置项，**鼠标左键点击选中它**（确保它前面有一个被勾选的状态，背景色变亮或带有对号图标）。

> **💡 进阶提示：订阅更新失败怎么办？**
> 如果你在导入或日后点击“更新”订阅时提示网络错误，通常是因为该机场的订阅服务器域名被国内运营商屏蔽了。此时，你可以先找一个免费节点连接，或者在手机上开好代理后开热点给电脑，在有代理的环境下再次点击更新。

## 第四步：理解代理模式与策略组

配置导入成功后，我们需要告诉软件如何处理你的网络流量。这是新手最容易迷惑的部分。

1. 点击左侧边栏的 **代理（Proxies）**。
2. 在页面顶部，你会看到三个主模式选项：
   - **规则模式（Rule）**：最推荐的日常模式！国内网站和应用（如微信、淘宝、B站）直连，不消耗机场流量；国外被墙网站（如 Google、GitHub）自动走代理。
   - **全局模式（Global）**：所有流量全部强制走代理。一般只在特定需求下使用（比如测试节点连通性，或者某些极为冷门的国外网站没被规则命中），日常极度不推荐。
   - **直连模式（Direct）**：相当于关闭代理功能，所有流量都不走节点。
   👉 **请确保你选中了“规则模式（Rule）”。**
3. 往下看，你会看到多个**策略组（Proxy Groups）**。这是 Clash 的核心功能，它帮你把节点分类。常见的策略组有：
   - `PROXIES` / `节点选择` / `Manual`：让你手动指定需要使用的国家/地区节点。
   - `UrlTest` / `自动选择`：软件每隔一段时间会悄悄测速，自动帮你切换到当前延迟最低的节点。适合懒人。
   - `Fallback` / `故障转移`：按列表顺序排，如果第一个节点挂了，自动无缝切换到第二个，优先保证可用性而不是延迟。
   - 展开策略组，挑选一个你喜欢的节点（比如 `香港 01` 或直接选 `自动选择`）。

## 第五步：开启系统代理 vs 进阶 TUN 模式

节点选好后，最后一步就是让软件真正接管你电脑的网络流量。Clash Verge 提供了两种接管方式，适合不同深度的用户。

### 方式一：系统代理（System Proxy）- 适合轻度网页浏览
如果你平时主要是用浏览器查资料、看 YouTube，系统代理完全足够了。
1. 点击左侧边栏的 **设置（Settings）**。
2. 找到 **系统代理（System Proxy）** 选项，将其右侧的开关打开（变成亮色）。
3. 至此，你就可以在浏览器中打开 Google 享受畅快的网络世界了。

### 方式二：TUN 模式（虚拟网卡）- 极度推荐，适合游戏、终端和全能场景
**系统代理的致命弱点在于**：很多非浏览器软件（例如大部分游戏、终端命令行 Git/npm、Windows UWP 商店应用、老旧的 ERP 软件等）根本不遵守系统的代理设置。这就导致你明明开了 Clash，这些软件依然连不上网。

解决这个问题的终极方案就是开启 **TUN 模式**。它会在你的电脑上创建一张虚拟网卡，强制接管整台电脑的最底层流量。

**开启步骤：**
1. 在 Clash Verge 中进入 **设置（Settings）** 页面。
2. 找到 **服务模式（Service Mode）**。如果是未安装状态，点击右侧的 **盾牌图标（安装/授权）**。在弹出的系统管理员授权框中点击“是”。安装成功后，盾牌旁边会显示绿色的 `Active` 或图标亮起。
3. 接着，在下方找到 **TUN 模式（Tun Mode）**，将开关打开。
4. **建议**：开启 TUN 模式后，你可以关闭上面的“系统代理”开关，因为 TUN 模式已经在更底层接管了流量，同时开启可能在某些系统环境导致回环冲突。开启 TUN 模式后，你的命令行工具、Steam、甚至一些原本连不上网的游戏都会立刻畅通无阻。

## 进阶玩法：如何添加自定义分流规则（Rules）

在使用过程中，你可能会遇到这样的情况：某个国外网站没有被内置规则命中，导致它走了直连打不开；或者某个国内公司的内网打卡系统，被误判走了代理导致登录失败。

Clash Verge Rev 允许你通过可视化的方式或者编写简单的脚本来解决这个问题：

**使用 UI 快速添加自定义规则：**
1. 在左侧边栏点击 **订阅（Profiles）**。
2. 右键点击你正在使用的机场配置，选择 **新建（New）** -> **新建本地配置（Local）**，或者直接使用软件内置的 **合并（Merge）** 功能。更简单的方法是使用 Verge Rev 的 **全局扩展脚本（Merge Scripts）**。
3. 不过，最适合新手的零代码操作是在 **设置** -> **路由设置 (Routing)** 中直接添加自定义规则。
4. 点击添加规则，常见的规则类型有：
   - `DOMAIN-SUFFIX`（域名后缀匹配）：如填写 `example.com`，则所有访问 `www.example.com` 或 `api.example.com` 的流量都会被拦截。
   - `DOMAIN-KEYWORD`（域名关键字）：如填写 `google`，任何域名中包含 google 字样的都会匹配。
   - `IP-CIDR`（IP地址段）：用于匹配特定的 IP 范围。
5. 将目标指向 `PROXY`（走代理）或者 `DIRECT`（直连），保存即可生效。这样你就可以精确地控制每一个网站的去向，调教出最适合自己工作流的网络环境。

## 常见问题与致命报错排查指南

在帮助过数千名用户配置代理后，我们总结了以下最常见的问题及其解决方案：

### 1. 开启代理后，彻底断网，连国内网站都打不开
- **系统时间不同步**：代理协议对时间校验非常严格。请右键系统托盘的时间，进入设置，点击“立即同步”以校准网络时间。只要时间误差超过两分钟，所有加密握手都会失败。
- **端口被占用**：检查右下角系统托盘的 Clash 图标是否变成了红色/灰色并提示 `Port conflict`。Clash 默认使用 `7890` 端口，如果你开着其他代理软件，或者某些开发工具占用了这个端口，就会启动失败。在“设置”中将混合端口（Mixed Port）改为 `7891` 或其他数字即可。

### 2. 浏览器能翻墙，但 Telegram（电报）一直在转圈连接中
Telegram 官方客户端默认是不走系统代理的。
- **解决方法 A**：在 Clash 中开启上文提到的 TUN 模式。
- **解决方法 B**：在 Telegram 内部设置：进入 `Settings` -> `Advanced` -> `Connection type` -> `Use custom proxy` -> `Add proxy`，选择 **SOCKS5** 或 **HTTP**，地址填写 `127.0.0.1`，端口填写 `7890`（与你 Clash 设置里的混合端口一致），保存并启用即可。

### 3. Windows 商店 (UWP) 应用无法联网
Windows 处于安全机制（AppContainer 隔离），禁止商店下载的 UWP 应用通过本地回环地址（127.0.0.1）访问网络。
- **最简单的解法**：开启 TUN 模式，它能无视 UWP 限制。
- **如果不方便开 TUN**：可以使用 Clash Verge 顶部菜单工具栏中的 **UWP Loopback 工具**，勾选全部应用并保存，解除网络隔离限制。

### 4. 节点列表一直测速失败（Timeout），怎么换节点都没用
- 确认你的机场套餐是否已经到期，或者流量是否已经耗尽。登录机场官网查看剩余流量。
- 如果你是从别人那里拷来的旧配置文件，可能机场的服务器 IP 已经更换。请前往“订阅”页面，点击你配置项右侧的 **更新（Update）** 刷新获取最新的服务器列表。
- 检查你是否有安装各种管家、360 等杀毒软件，它们极有可能会将底层代理内核（如 `mihomo.exe` 或 `clash-meta.exe`）拦截并删除。请将其加入杀软白名单。

### 5. 访问某些国内网站感觉变慢了？
这通常是因为 DNS 泄露或假 IP（Fake-IP）污染引起的。如果在“规则模式”下国内网站加载明显卡顿，你可以在 Clash Verge 的“设置”里，找到 DNS 设置，将模式从 `Fake-IP` 尝试切换回 `Redir-Host`（虽然现代内核下 Fake-IP 已经很完善，但特定局域网环境下仍可能出现水土不服），或者开启“启用内置 DNS”并重置其设置。

通过以上这套完整的配置和排查流程，相信你已经能够驾驭 Clash Verge 这款神器，获得丝滑顺畅的国际网络冲浪体验了。如果你有更复杂的定制需求，也可以参考其官方文档探索更多关于 Rule Providers 和 Scripting 的高级功能。
